AgentMeter

Pay-per-call USDC metering for software-to-software payments on Arc.

Built by one person with AI (Claude Code) assistance for the Arc Microgrants round 2 hackathon. No wallet is ever asked to sign anything except the actions you press below. Read the flow and the README before sending real USDC.

1. Network & wallet

not connected

2. How it works

  1. registerProvider(pricePerCall) — a service registers once and gets a providerId.
  2. topUp(providerId) — a caller prepays USDC credit against that provider's channel.
  3. recordUsage(providerId, caller, calls) — only the provider can call this; it charges calls × pricePerCall straight out of the caller's channel credit, or reverts if credit is too low.
  4. withdrawEarned() / withdrawUnused(providerId) — the provider pulls what it earned, the caller pulls back whatever credit is left.
